👥 Guía de Colaboración y Uso para el Equipo

¿Es tu primera vez colaborando en el repositorio grupal? Sigue las pestañas a continuación para aprender a subir tu código y detectar errores automáticamente.

Paso A: Unirse al Repositorio
Pídele al administrador del proyecto (Samuel) que te agregue como colaborador en GitHub (Settings > Collaborators) para tener permisos de escritura.
Paso B: Clonar el Proyecto en tu PC
Abre tu terminal o VS Code y clona el proyecto con el siguiente comando:
git clone https://github.com/K6Samuel/Sonia_Caso.git
Crea tu propia rama de trabajo
Nunca programes directamente sobre main. Crea una rama con tu nombre:
git checkout -b tu-nombre-rama
Sube tus cambios al servidor
Una vez modifiques o agregues tus archivos, ejecuta los comandos de envío:
git add .
git commit -m "Agregando mi parte del estudio de caso"
git push origin tu-nombre-rama
¿Cómo sabe el sistema si tu código tiene errores?
Cuando hagas un Pull Request en GitHub para unir tu rama a main, el robot Super-Linter revisará línea por línea tu código automáticamente.

⚠️ ¿Qué pasa si encuentras una X roja (Failing)?

Significa que hay un error de sintaxis o una mala práctica. Haz clic en Details dentro de los checks de GitHub para ver la línea exacta que falló, corrígela en tu PC y vuelve a hacer push.
