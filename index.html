Flujo de colaboración

Cómo trabajar sin romper el código

Cuatro pasos que sigue todo el equipo antes de que un cambio llegue a producción.

01

Clonar el repositorio

Descarga una copia local del proyecto para empezar a trabajar en tu máquina.

bash 
$ git clone https://github.com/codeando-srl/proyecto.git
02

Crear tu carril de trabajo

Cada tarea vive en su propia rama: así tu trabajo nunca interfiere con el de otra persona ni con main.

bash 
$ git checkout -b tu-rama
03

Subir tus cambios

Guarda tu progreso en commits pequeños y descriptivos, luego súbelos a tu rama remota.

bash 
$ git add .
$ git commit -m "Describe tu cambio"
$ git push origin tu-rama
04

Fusión segura (Pull Request)

Abre un Pull Request. Antes de unirse a main, tu código pasa por una revisión automática (Super-Linter) y, si todo está en orden, se fusiona sin sorpresas.

bash 
$ gh pr create --fill
